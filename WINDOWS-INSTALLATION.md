# Project Phoenix pour Windows

Le fichier `Project-Phoenix-Setup-3.1.0.exe` est fabriqué automatiquement par GitHub Actions.

## Installation

1. Télécharge l’archive `Project-Phoenix-Windows-Installer` depuis l’onglet **Actions**.
2. Décompresse l’archive ZIP.
3. Lance `Project-Phoenix-Setup-3.1.0.exe`.
4. Windows peut afficher un avertissement SmartScreen car l’application n’est pas signée par un certificat payant. Choisis **Informations complémentaires**, puis **Exécuter quand même** si le fichier provient bien de ce dépôt.
5. L’installateur crée un raccourci sur le Bureau et dans le menu Démarrer.

Les données sont enregistrées localement sur le PC. Cette version Windows ne peut pas lire directement Apple Santé, car Apple réserve HealthKit à l’iPhone et à l’Apple Watch.
